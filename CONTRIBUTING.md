# Contributing to the Bidirekt broker

## Bugs and feature requests

Open an issue in this repository, with the **Bug report** or the **Feature request** form.

## Questions

For questions about using Bidirekt, read the docs at https://bidirekt.com/docs.

## Pull requests

Fork the repository, create a branch, and open a pull request against `main`. The CI checks must pass before it is merged. The README says how to set up the hook that runs the tests before every push.

## CLA

Pull requests ask you to sign the [Contributor License Agreement](CLA.md). A bot comments on the pull request; sign it by posting a comment whose entire text is this exact phrase:

```
I have read the CLA Document and I hereby sign the CLA
```

## Security

Report a vulnerability as [SECURITY.md](SECURITY.md) describes, never in an issue.
