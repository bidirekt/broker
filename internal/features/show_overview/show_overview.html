Put data in from your pipelines

The CLI and CI fill the broker. Run these in order; each command has --help.

  1. Create an API key in your Profile, then run bidirekt login.

  2. Register each service once, by its snake_case name.

    bidirekt create-participant

  3. Create the environments you deploy to, like staging and production.

    bidirekt create-environment

  4. Publish a version of a participant's contract from your CI.

    bidirekt publish

  5. Before a deploy, ask whether this version is compatible with what's deployed.

    bidirekt can-i-deploy

  6. Deploy the version with your own pipeline.

  7. After a deploy, record which version is now running where.

    bidirekt record-deployment
